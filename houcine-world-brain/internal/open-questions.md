# Open questions for the owner (internal, never sent to an agent)

The concierge says "not published" for each of these until the owner confirms an answer and a session adds it to the
right public note (with a source):

## La Rosa View
- Prices, packages or a starting rate for a DJ set, and whether travel costs apply.
- Which cities or countries La Rosa View travels to.
- Typical set length, equipment provided or needed, and technical requirements.
- Deposit, payment methods and cancellation terms for La Rosa View bookings.
- Whether there is a public calendar of upcoming performances.
- Whether La Rosa View has its own phone or WhatsApp number to publish.

## How to answer one
Edit the public note named in brackets, cite where the answer comes from (add a source id in
`sources/website.md` if needed, for example `owner-confirmation-2026-11-02`), then rebuild the index
(`docs/knowledge-brain.md`).
